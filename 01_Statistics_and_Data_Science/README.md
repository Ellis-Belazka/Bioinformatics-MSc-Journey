# Statistics and Data Science

This folder contains my practical work for the Statistics and Data Science module of the MSc Bioinformatics at Birkbeck, University of London (2026–2027).

It records my progress in using R for data handling, statistical analysis and visualisation, beginning with the fundamentals of the language.

## Practicals

| Practical | Focus |
| --- | --- |
| [01 — Introduction to R](01_Introduction_to_R/) | Arithmetic, variables, vectors, logical indexing, importing data, summary statistics, boxplots and histograms |

I will add further practicals as I complete them. Each practical has its own numbered folder containing the script, accompanying data where included, and a README with context and run instructions.

## Skills practised so far

- Creating variables, vectors and sequences in R.
- Selecting values using positions and logical conditions.
- Importing a text dataset and working with data-frame columns.
- Separating observations into groups and calculating summary statistics.
- Creating and customising plots using base R graphics.

## Running the exercises

See the README inside each practical for its requirements and instructions. For the first practical, run the code section by section with the working directory set to that practical’s folder so that R can find the accompanying dataset.
