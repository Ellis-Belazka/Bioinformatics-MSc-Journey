# Practical 1 — Introduction to R

**Module:** Statistics and Data Science  
**Programme:** MSc Bioinformatics, Birkbeck, University of London  
**Completed:** October 2026

## Overview

This is my first introductory R practical for the MSc. It moves from basic calculations and vector operations to importing a biological dataset and exploring protein interface areas for monomers and dimers.

The aim was to practise the fundamentals of R and become familiar with handling data and producing plots. This is a learning exercise rather than a complete statistical investigation.

## Skills practised

- Arithmetic, variable assignment and built-in mathematical functions.
- Creating and combining vectors and generating sequences.
- Selecting elements by position and logical conditions.
- Using `sum()` and `which()` with logical vectors.
- Creating polynomial plots and customising lines, colours and axes.
- Importing a text file with `read.table()` and naming its columns.
- Separating monomer and dimer observations using logical indexing.
- Calculating group summaries with `summary()`.
- Comparing distributions using boxplots and histograms.

## How to run

1. Download both files and keep them together in this folder.
2. Open `01_intro_to_r_practical.r` in R or RStudio.
3. Set R’s working directory to this folder, `01_Introduction_to_R`. Use `getwd()` to check the current location.
4. Run the script section by section, from top to bottom, to inspect the calculations and plots.

The script uses base R; no additional packages are required. RStudio is optional.

## Outputs and notes

The practical produces polynomial plots, protein interface boxplots, monomer/dimer summary statistics and histograms. Plots are displayed in the active graphics window or RStudio’s Plots pane. The example JPEG export code at the end is commented out, so images are not automatically saved.

The vector examples include `log(v)` when `v` contains `-1`. R returns `NaN` for that element with a warning because the real-valued logarithm is undefined for negative values. This also affects the corresponding element in `exp(log(v))`.

The side-by-side boxplots currently use a vertical range of 0–6000. The dataset contains a dimer area of 7166.8, so that value lies outside the displayed boxplot range.
